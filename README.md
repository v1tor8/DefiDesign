# DefiDesign

Decentralised, state-machine-based architecture enables dynamic, auto-scaling liquidity engines for robust, distributed financial platforms.

The key benefits of using DefiDesign include:

- Decentralised, state-machine-based architecture enables dynamic,
- auto-scaling liquidity engines for robust,
- distributed financial platforms

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DefiDesign.git`
2. `cd DefiDesign`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure DefiDesign, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
